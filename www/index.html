Outfits favoritos

El recorte de fondo NO identifica automáticamente una camisa separada de quien la lleva puesta. Revisa y edita la máscara antes de guardar. El recorte automático es experimental y puede tardar o fallar en algunos teléfonos. Si falla, se guarda la foto original. Tus datos se guardan localmente en este navegador. Para evitar perderlos, no borres los datos del sitio. Las fotografías no se suben a ningún servidor de análisis; el modelo se descarga al dispositivo desde un proveedor externo. La IA requiere conexión inicial y un navegador compatible.
